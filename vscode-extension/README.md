# TALON Language Support for VS Code

VS Code language support for the TALON Exploit Development Language.

---

## Features

- Syntax highlighting
- Auto-completion
- Integrated GDB debugging
- Visual memory viewer
- Drag-and-drop ROP builder
- Exploit templates and helpers

---

## Installation

Install via VSIX or Marketplace.

---

## Commands

- TALON: Run Exploit
- TALON: Start Debugging
- TALON: Insert Exploit Template
- TALON: Auto-Find Buffer Offset
- TALON: Show Memory Visualizer
- TALON: Show ROP Chain Builder

---

## Requirements

- VS Code 1.70+
- TALON binary in PATH
